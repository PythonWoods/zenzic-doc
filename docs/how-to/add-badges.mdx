# Official Badges & CI/CD Integration

Zenzic provides two official badge types. Add them to your project’s `README.md` to signal documentation integrity to contributors and users.

---

## ✅ Zenzic Audit Badge (Binary Status)

![Zenzic Audit badge](../assets/brand/svg/zenzic-badge-audit.svg)

Use this badge to certify that your documentation has passed Zenzic's full integrity check: structural links, credential scanner (Z201–Z204), and path traversal guard (Z202–Z203). It is a binary gate: **audit: passed** or **audit: failed**.

### Copy-paste Markdown

**Passing (green):**

```markdown title="README.md"
[![Zenzic Audit](https://img.shields.io/badge/zenzic-audit:_passed-success?style=flat-square)](https://zenzic.dev/docs/how-to/add-badges/)
```

**Failing (red):**

```markdown title="README.md"
[![Zenzic Audit](https://img.shields.io/badge/zenzic-audit:_failed-critical?style=flat-square)](https://zenzic.dev/docs/how-to/add-badges/)
```

### Recommended CI step

```yaml title=".github/workflows/zenzic.yml"
- name: Audit documentation (Zenzic)
  run: uvx zenzic check all --strict
```

Place the `audit: passed` URL in your README. If this step fails in CI, manually swap the badge to `audit: failed` — or automate it via [dynamic-badges-action](https://github.com/Schneegans/dynamic-badges-action) (see [CI/CD Integration](./configure-ci-cd.mdx)).

> **Why “audit”?** The badge certifies that the documentation corpus has passed deterministic structural integrity and security checks — not a stylistic review. `audit: passed` maps directly to `zenzic check all --strict` exit code 0.

## 💯 Zenzic Score (Improvement Metric)

![Zenzic Score badge](../assets/brand/svg/zenzic-badge-score.svg)

Use this badge to expose the live quality score (0–100) of your documentation. Ideal for established projects adopting Zenzic progressively: a green build can still show a non-perfect score, encouraging continuous improvement without blocking the workflow.

### Copy-paste Markdown

```markdown title="README.md"
[![Zenzic Score](https://img.shields.io/badge/zenzic_score-100%2F100-4f46e5?style=flat-square)](https://zenzic.dev/docs/how-to/add-badges/)
```

### Using `--fail-under` for progressive adoption

```bash
# Green CI at 72/100 — build passes, score is visible
zenzic score --fail-under=70

# Red CI at 72/100 — floor not met
zenzic score --fail-under=80
```

The `--fail-under` flag decouples the exit code from the score value. Teams can start at a realistic floor (e.g. 60) and raise it sprint by sprint.

## 📊 Live Score Badge via JSON

`zenzic score --save` writes `.zenzic-score.json` at the repo root:

```text
{"project": "zenzic", "score": 100, "threshold": 0, "status": "success", "timestamp": "...", "categories": [...]}
```

This file is the machine-readable bridge to dynamic Shields.io badges.

### Automate with GitHub Actions

The following two steps save the score and push it to a [GitHub Gist](https://gist.github.com) that Shields.io reads on every request:

```yaml title=".github/workflows/zenzic-score.yml"

- name: Compute Zenzic Score

  run: |
    uvx zenzic score --save
    echo "SCORE=$(uvx zenzic score --format json | python3 -c \
      'import sys,json; print(json.load(sys.stdin)["score"])')" >> "$GITHUB_ENV"

- name: Update Score Badge

  uses: Schneegans/dynamic-badges-action@<version>
  with:
    auth: ${{ secrets.GIST_SECRET }}
    gistID: <your-gist-id>
    filename: zenzic-score.json
    label: "zenzic score"
    message: "${{ env.SCORE }} / 100"
    color: ${{ env.SCORE == '100' && '4f46e5' || env.SCORE >= '80' && 'f59e0b' || 'ef4444' }}
```

Then reference the dynamic endpoint in your README:

```markdown title="README.md"
[![Zenzic Score](https://img.shields.io/endpoint?url=https://gist.githubusercontent.com/<user>/<gist-id>/raw/zenzic-score.json)](https://github.com/PythonWoods/zenzic)
```

**Setup:** create a Gist, generate a Personal Access Token with `gist` scope, save it as `GIST_SECRET` in your repo secrets, and replace `<your-gist-id>`. See [CI/CD Integration](./configure-ci-cd.mdx) for the complete workflow.

## 🎨 Offline / Enterprise Badges

Projects in air-gapped or enterprise environments that cannot call `img.shields.io` can embed the official static SVG assets from the Brand Kit directly:

| File | Description |
|---|---|
| `zenzic-badge-audit.svg` | Static “audit: passed” badge |
| `zenzic-badge-score.svg` | Static “100 / 100” score badge |

**Note:** `brand-kit.zip` is a build artifact. It is not stored in the repository — download it
from the [GitHub Releases](https://github.com/PythonWoods/zenzic/releases/latest) page, or
generate it locally with `nox -s build`.
