## Features

<div class="grid cards" markdown>

-   :material-shield-check:{ .lg .middle } **Zero-Config Security**

    Scan for hardcoded credentials, API keys, and path traversal vulnerabilities out of the box. Security checks cannot be suppressed.

-   :material-link-variant:{ .lg .middle } **Graph-Aware Link Validation**

    Resolves relative links and anchors against a virtual site map. Zenzic checks whether the build engine will serve the page, not just file existence.

-   :material-trending-up:{ .lg .middle } **Document Quality Score (DQS)**

    Measures documentation health on a 100-point scale. Track improvements and regressions over time with deterministic scoring.

-   :material-transit-connection-variant:{ .lg .middle } **Engine-Agnostic Adapters**

    Native integration with MkDocs and Zensical, and a zero-assumption Standalone mode for raw Markdown folders.

</div>
