# Zenzic: The Engineering Standard for Documentation Integrity

Zenzic is an engine-agnostic static analyzer for Markdown-based documentation.
It operates in the **Build-Aware Gap** — the critical window between authoring
source files and their transformation into a published site — building a
**Virtual Site Map (VSM)** to validate links, detect orphans, scan for exposed
credentials, and enforce quality rules without ever invoking the documentation build.

---

## Start Here: `zenzic lab`

The fastest way to experience Zenzic is to run the interactive showcase.
No configuration, no setup — pull and run:

```bash
uvx zenzic lab
```

`zenzic lab` walks through a live audit of bundled documentation examples,
showing every scanner in action: broken links, orphan pages, credential detection,
and Blood Sentinel path-traversal enforcement.

## Enterprise Ready

Zenzic integrates natively with professional CI pipelines:

- **SARIF 2.1.0 export** — `check all --format sarif` produces a report that GitHub Code Scanning
  reads directly. Findings appear as inline Pull Request annotations and in the Security tab,
  without log parsing.
- **Official GitHub Action** — [`PythonWoods/zenzic-action`](https://github.com/PythonWoods/zenzic-action)
  handles installation, execution, and SARIF upload in a single workflow step.
- **Cross-platform validation** — every release is tested on Ubuntu, Windows, and macOS across
  Python 3.11–3.13.

```yaml
- uses: PythonWoods/zenzic-action@v1
  with:
    format: sarif
    upload-sarif: "true"
```
