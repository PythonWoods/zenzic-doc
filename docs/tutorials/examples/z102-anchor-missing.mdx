# z102-anchor-missing — Anchor Integrity

**Z-Code:** `Z102 ANCHOR_MISSING` · **Engine:** `standalone` · **Exit:** `1`

<Z102AnchorMissing />

## The Fixture

The fixture lives at `examples/z102-anchor-missing/` in the Zenzic repository.
It contains two documents:

| File | Role |
| :--- | :--- |
| `docs/index.md` | Source — contains the broken fragment link at line 11 |
| `docs/guide.md` | Target — exists on disk but lacks the referenced heading |

`docs/index.md` line 11 links to `guide.md#nonexistent-section`. The target file
`guide.md` exists and contains one valid heading — `## Overview` (anchor `#overview`) —
but has no `#nonexistent-section` heading. Zenzic resolves the file, scans its headings,
finds the dead fragment, and fires Z102.

```toml title="examples/z102-anchor-missing/.zenzic.toml"
docs_dir = "docs"
fail_under = 0

[build_context]
engine = "standalone"
```

## Running the Example

```bash
# Clone the Zenzic repository — no install required
cd examples/z102-anchor-missing
uvx zenzic check links
```

Expected output:

```text
docs/index.md:11:31 ✘ [Z102] guide.md#nonexistent-section — anchor not found on target page

	9  │  ## Broken Anchor Reference
   10  │
   11  ❱  - [Nonexistent Section](guide.md#nonexistent-section)
	   │                               ^^^^^^^^^^^^^^^^^^^^
   12  │
```

Exit code: `1`

Anchor context (documentation note, not CLI output):

- Present in `guide.md`: `#guide`, `#overview`
- Missing in `guide.md`: `#nonexistent-section`

## Understanding the Output

The Z102 finding reports:

- **Source file and line** (`docs/index.md:11`) — the exact location of the broken fragment link.
- **Z-code** (`Z102`) — violation class: the target file exists, but the anchor does not.
- **Rule name** (`ANCHOR_MISSING`) — canonical identifier for this check.
- **Dead fragment** (`guide.md#nonexistent-section`) — the link destination Zenzic could not resolve.

The key distinction from Z101:

| Code | What is missing | Target file exists? |
| :--: | :-------------- | :-----------------: |
| Z101 | The target **file** | ✘ |
| Z102 | The target **heading anchor** within an existing file | ✔ |

Z102 is a **standalone-engine check**: Zenzic reads `guide.md` from disk, parses its
headings, and checks whether the fragment `#nonexistent-section` resolves. No network
request is made. The heading `#overview` is valid and present — only `#nonexistent-section`
is missing.

## Fixing the Violation

Either add the missing heading to `guide.md`:

```markdown title="docs/guide.md (after fix)"
## Nonexistent Section

Content for this section.
```

Or correct the link in `index.md` to reference the heading that actually exists:

```markdown title="docs/index.md (after fix)"
- [Overview](guide.md#overview)
```

Then rerun:

```bash
uvx zenzic check links  # → exit 0, no findings
```
