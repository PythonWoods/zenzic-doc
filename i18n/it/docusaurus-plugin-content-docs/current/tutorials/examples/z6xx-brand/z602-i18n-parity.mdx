## Interpretare l'Output

Il codice di errore `Z602` indica un problema di tipo **I18N_PARITY**.

Questo errore o avviso viene generato da Zenzic quando esiste un problema di parità di traduzione. Una pagina è presente nella lingua base (es. inglese) ma manca il corrispondente file tradotto nella lingua di destinazione (es. italiano), oppure i metadati di frontmatter non coincidono. In questo esempio specifico:
- **Tipo di Scansione:** `I18N Parity Guard`
- **Severità:** `Warning / Governance Gate`
- **Impatto:** Le violazioni di parità di traduzione indicano un lavoro di localizzazione incompleto, influenzando i calcoli dei punteggi di governance.
## Correggere la Violazione

Risolvi il problema come riportato da Zenzic.
